# 作业格式与全量交付门禁

适用于本技能新生成、模拟或按授权重新排版的学生作业，单份、样例和全班均执行。用户后续明确指定其他形式时以其要求为准并记录差异。真实原始作业、教师原批注和签名只读保护；本规则不授权删除原始证据。课程人数、题数、颜色、分数和页数从当前任务取得，不能照搬某次批次。

## 生成时就避免三类问题

- **题分前无框。** 题分用独立文字run写成 `+4`、`+9`、`+0` 等，前面直接连接题干或仅用普通半角空格；不使用全角空格 U+3000、字面方框或控件作垫位。Word显示格式标记时，全角空格可显示为空框，搜索字面“□”会漏检。检查范围包括身份栏、选项间距、题分位置及页眉页脚；新生成作业的排版间距使用普通半角空格或段落定位，不使用全角空格U+3000作垫位，否则开启格式标记仍会显示成框。保留题目本身有意义的填空框、集合/逻辑/公式符号，不得误删题意。用户要求清除全部排版框时，不能以“正常全角空格”解释为允许保留。
- **学生正文无扣分批注。** 不生成“未完成评分点…扣…分”“未作答，得0分”“最终计算错误，扣1分”等评语，也不生成空的评语占位段或Word批注。只保留要求的答案、题分、总分及身份。命中知识点、扣分依据和模拟说明放独立核验表，不能因去掉正文评语而丢掉判分依据。
- **无左侧黑点来源。** 对正文、标题、题干、选项、答案、空白段、表格、页眉页脚中的每个段落，显式设置 `keepNext=0`、`keepLines=0`、`pageBreakBefore=0`、`suppressLineNumbers=0`，同时清理样式中的相应true值。仅删除直接属性可能重新继承true；`python-docx` 中的 `None` 也表示继承，应设 `False`。辅助函数不能固定写 `keep_together=True` 或沿用 `keep_with_next=True`。不使用真实项目符号给题干和选项编号，保留正常题号和A—D文字。
- 采用实际分页符/分节保持批准页界，不能用“与下段同页”等属性硬顶页数。控制属性清理后重新验证分页、题干选项同页和作答完整性；不能缩小字体凑页。
- 已验收母版、旧生成器和旧验证报告不能覆盖这些最新要求。先检查并修正母版及生成函数，生成后仍检查最终文件；不通过反复隐藏格式标记或更改用户全局显示设置掩盖问题。

## 标题与附加内容

- 卷名整行显式统一中文、ASCII数字、英文和复杂文字的字体、字号与粗细；核对 `rFonts` 的 eastAsia/ascii/hAnsi/cs，`sz/szCs` 及 `b/bCs`。只写字号和bold仍可能继承Title样式的不同字体，产生混排。
- 新生成学生作业默认不加作业名称页脚、页码或“单项选择题 续”等重复续页标题。保留必要题型名称；每题/共计分值说明、页脚和其他附加标签服从当前用户要求，不能沿用旧实例自动添加。已有真实模板的页脚仍按授权范围处理。
- 全量直接扫描U+3000、字面框、页脚引用和实际footer部件、续页标题、卷名字体属性。用户已指出WPS显示问题时，打印PDF没有框不能推翻该反馈。格式修改后旧WPS截图和旧渲染哈希只作历史记录，不能继续标记为当前版本实看通过。

## 交付前必须覆盖全部实际文件

1. 从冻结名单/授权范围建立清单，核对每个学生×作业恰好一份、期望总数和各目录数量。检查源文件只读哈希；备用样例、审核PDF是否同步以任务范围为准，不能让旧版样例覆盖新成品。
2. 重新打开全部实际保存文件，逐份检查三类格式问题；不能只看一份母版、抽几名学生或搜索字面方框。记录文件哈希、题分字段数、检查结果和全部异常，不能遇到第一处错误便跳过余下文件。
3. 从实际答案独立判分，检查 `实际答案支持的逐题分数 = 题干标分`，以及 `各题合计 = 抬头总分 = Excel对应源单元格`。算术相等不证明答案应得该分，不能用生成器登记的预期命中点代替语义复核。重复答案可严格按题号、完整答案和题分归组逐种复核，再逐份回查。原先的“缺少倍字”“未另写均为8位”等机械判词不能压过等价正确表述。
4. 完整渲染所有最终文件并核对页数、每页题号、选项、答案、题分颜色、页脚页码、裁切和重叠。固定母版可采用已人工查看的静态像素比对加全部动态字段检查；所有无法解释的差异必须看图处理。只看PDF不会显示Word非打印段落标记，因此不能替代第2步。
5. 原生Word可用时，使用自建隐藏实例，只读检查每种最终版式的有效 `KeepWithNext`、`KeepTogether`、`PageBreakBefore` 和 `ListType`，并保留结果。不得关闭用户Office或改变用户全局显示选项。原生Word失败时保留错误，完成全量OOXML直接属性/样式检查与渲染，并明确“原生Word未验证”，不能把LibreOffice结果说成原生Word验证。
6. 交付前运行下列检查脚本，要求期望文件数、每份题分字段数、有效段落属性、评语、当前哈希及渲染证据全部通过。任何文件漏查、结构异常、旧哈希/旧渲染或未解释差异都不能宣称全批通过。修订后的文件必须刷新清单、CSV中的正文批注/段落号、哈希及对应PDF/PNG证据；原扣分依据可另列“仅核验用”。

## 格式检查脚本

[check_homework_format.py](../scripts/check_homework_format.py) 只读扫描指定交付目录，汇总全部异常并返回非零退出码；不修改作业，也不判断答案语义、Excel成绩或图像视觉内容。仅依赖Python标准库。

```text
python scripts/check_homework_format.py --root <学生作业目录> --expected-count <文件总数> --expected-score-count <每份题分字段数> --score-color <题分颜色如C00000> --render-report <当前渲染证据.json> --output <格式全量检查.json>
```

`--root` 可重复指定，样例目录按授权范围纳入，不能把评分标准或原始材料目录混入。题分颜色按本批传入；空白试卷可传 `--expected-score-count 0`。`.doc` 不会被当作DOCX略过：脚本会报不支持，必须另用最终DOC原生检查，必要时另存只读检查副本；不能改后缀冒充格式通过。

渲染证据为 `{"records":[...]}`，每条包含：

```json
{"file":"最终DOCX绝对路径","docx_sha256":"当前Word哈希","pages":4,"layout_checked":true,"unexplained_differences":0,"images":[{"file":"页图绝对路径","sha256":"页图哈希"}]}
```

页数示例不固定本批页数。每页均需图像、存在且哈希匹配；`layout_checked` 必须来自已完成的实际版面检查，不能为了通过脚本补写。原生Word状态另外如实记录。`--structure-only` 只供生成阶段调试，结果为 `STRUCTURE_ONLY_PASS`，不得用它代替最终交付检查。脚本通过也不能替代身份、答案/题分和Excel复算。

## 检查器的范围

脚本检测题分字段前的全角空格/方框、部分扣分评语、段落与样式控制属性、真实列表、批注标记、文件数量，以及提供的渲染证据和当前哈希。它不覆盖所有位置的全角空格、卷名字体一致性、全部页脚/续页标题规则，也不识别答案语义或检查图像像素。这些规则仍需独立的全文结构检查、判分及实际渲染验收。`layout_checked` 是外部检查者提供的结果，不是脚本作出的视觉判断。测试里的微型PNG仅验证证据校验分支，不是课程排版样例。
