# Excel、公式与课程目标达成度

## 确认输入与计算口径

1. 明确处理独立文件还是已连接的工作簿。使用当前可用通道及其实际能力，核对完整路径、工作表和数据范围；不默认选择第一个工作簿。
2. 有界读取身份、原始成绩、相关公式、表头、隐藏行和合并单元格。记录学生集合与原顺序、工作簿版本、受保护区域和有关图表的系列基线。
3. 根据当前考核方案确认项目到目标的映射、满分、贡献权重、统计人数、缺考/缺失规则及舍入方式。列号、行号和人数不能从其他课程复用。
4. 贡献权重已经包含平时/期末比例时，不再乘一次。常见口径为：

   `目标达成度 = Σ(项目得分 / 项目满分 × 项目贡献值) / Σ(项目贡献值)`

   仅纳入映射到该目标的项目；实际课程规则优先。至少手工核对一项，防止两套程序使用同一份错误映射。
5. 区分未舍入值与显示值。个人值的舍入平均可能不同于未舍入值的平均；先依课程口径计算，最后显示。阈值判断使用规定精度，通常应使用未舍入值。

## 写入与全量核验

- 先冻结输入快照并独立复算全部学生；缺失或冲突不能作为0填入。
- 仅写获准区域。数值与公式分块处理，避免整块覆盖无关公式、格式和原始成绩。
- 改权重时同步核对获准范围内的说明、分项贡献、个人公式、汇总、评价页和图表；只改权重不代表可以重新生成成绩。
- 统一重算，检查全部相关公式结果与错误值，比较身份、顺序、受保护数据和修改区域。
- 图表另核对系列、X/Y、点数、来源、阈值及自动标签，见 [图表流程](attainment-chart-style.md)。保存后重新读取并按能力进行原生检查。
- 直接修改XLSX内部XML时保留命名空间和无关部件；不能用通用XML重新序列化后“能解压”代替Excel打开核验。

## 独立复算脚本

从仓库根目录运行：

```text
python skills/engineering-accreditation/scripts/check_attainment.py --csv examples/attainment/scores.csv --config examples/attainment/rules.json --output work/demo-calculation.json --observed examples/attainment/expected-results.json
```

全部演示值均为虚构。实际课程须自行导出正确快照并配置规则，不能套用演示权重。

CSV使用UTF-8或带BOM的UTF-8，首行为不重复字段名，每学生一行。身份字段保持文本，含前导零时不转为数字。配置字段：

| 字段 | 含义 |
|---|---|
| `identity_columns` | 组成唯一学生键的字段名列表 |
| `expected_count` | 可选的预期有效学生数 |
| `decimals` | 显示小数位数，0至12 |
| `column_maxima` | 可选的单列满分检查，合并多列计分时建议补全 |
| `objectives[].id` | 互不重复的目标标识 |
| `objectives[].items[].columns` | 同一个考核项目参与求和的成绩列 |
| `full_score` | 该项目列合计的满分 |
| `contribution` | 该项目对本目标的贡献值 |

脚本使用标准库Decimal，以ROUND_HALF_UP输出显示值。检查身份唯一性、人数、成绩范围与配置合法性；汇总为未舍入个人达成度的平均。输出中的`exact`是50位Decimal精度下的计算结果，循环小数仍有截断或舍入，并非无限精度值。

`--observed`用于核对独立读取的Excel结果：每学生的`key`和各目标`rounded`，以及汇总每目标的`exact`、`rounded`。顺序与身份须一致；学生显示值须完全一致，汇总未舍入值容差为1e-9，汇总显示值须一致。脚本不比较每个学生的未舍入值，需另行核查时自行补充。

未提供`--observed`时为`computed_only`。提供后成功显示`excel_numeric_results_matched`，这是脚本沿用的字段名称，只表示提供的观察值与计算值匹配；程序不会确认观察值是否来自Excel。使用仓库演示文件时，只能报告“演示结果匹配”。

脚本不读取工作簿，不验证快照提取是否正确，不验证公式结构、图表或版式。它要求相同满分/贡献规则及完整数值，不自动处理缺考剔除、不同学生分母或复杂课程公式。需要排除人员时先按依据形成有效快照，并单独核对排除清单及原始顺序；不适用时另做计算。

输出含输入文件路径、SHA-256和学生键，属于本地审计材料，公开前另行脱敏。原始工作簿或在线快照版本也应记录。
