# 课程目标达成度图表

当前模板或用户指定样式优先。以下是可选的通用样式，不是认证标准，也不固定目标数、权重或阈值。公开版不包含私人项目截图。

## 数据绑定

- 柱状图引用当前目标汇总单元格，类别与目标对应，采用自动数值标签。显示精度不改变原始计算或阈值判断。
- 散点图每名有效学生一个点，X为原学生序号、Y为对应目标达成度；不为排除者填0点，也不重排原序号。
- 用户要求直接引用原表时，排除行形成多段数据可使用多个同色系列，每段引用连续有效范围。每段逐项检查X/Y、点数及首末行。
- 汇总分子、分母和散点纳入名单保持一致。不能仅删除散点而继续在汇总中计入被排除者。
- 优先保留现有图表对象；重建或重排仅限获准图表，不清除无关对象或原始数据。

## 可选竖排样式

无指定模板、用户需要统一风格时，可使用汇总柱状图在上、各目标散点图依次在下的布局。图宽、左边界和图注对齐，避免覆盖成绩表；目标数不同则调整图数。

| 元素 | 示例设置 |
|---|---|
| 柱形 | 单色蓝色、平面、自动显示两位小数 |
| 散点 | 蓝色圆点、不连线，每名有效学生一个点 |
| 阈值 | 红色水平虚线，值及标注来自当前课程规则 |
| 背景 | 白色，浅灰网格，无阴影和渐变 |
| 字体 | 使用环境可用的中文字体，标题和图注清楚可读 |
| 纵轴 | 对0至1的达成度通常展示0至1并适当留白 |
| 横轴 | 按原学生序号最大值设置上界及间隔 |

可选色值：柱`#1F77B4`、散点`#468EBC`、标题`#4F81A4`、阈值`#FF0000`、网格`#E1E1E1`。不得为适应坐标轴截掉异常点；先核查数据。

## 验收

核对单元格、系列引用/实际数值、屏幕标签三层结果。保存后重开，看整张工作表与每张图，检查图注、刻度、标题、阈值和重叠。未亲眼检查UI选择范围时，只能说明已读取系列引用，不能宣称看到了彩框选择效果。原生操作要点见 [Excel核验](excel-native.md)。
