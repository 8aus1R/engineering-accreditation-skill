# 跨学年与跨班级分析

不同批次应分别冻结源文件、课程规则、有效名册、满分、目标映射和舍入口径。不直接把某批次的列号、权重、人数或结论套入另一批次。

1. 为各批次建立统一含义的指标映射，区分课程方案变化与表现变化。目标名称相同不保证考核口径相同。
2. 明确缺考、免修、缺失和特殊名单的依据；0分仍是实际数值。保留排除原因与纳入人数，不把用户排除人员重新列为待处理。
3. 分别核对个人达成度、汇总分子和分母。平均时记录是否按人数加权；班级均值的简单平均不一定等于合并学生均值。
4. 用未舍入结果判断阈值与趋势，并记录可比性限制。旧图缓存与显示两位小数不能用于反推精确值。
5. 对比图引用当前各批次汇总位置，核对目标顺序、图例、来源和阈值。是否创建辅助区或独立工作表按当前要求决定。
6. 用户提出“固定总评，同时让各目标落入指定区间”时，先做约束可行性分析。不可行则给出计算依据，不通过改真实分数或隐蔽舍入逼近目标。

交付保留各批次的独立核验结果；不能只验证合并后的一个平均数。
